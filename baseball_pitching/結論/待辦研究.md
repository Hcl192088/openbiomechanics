# 待辦研究

## 1. 哪種投手的能量轉移大（除了體重）

- 背景：`elbow_transfer_fp_br`、`shoulder_transfer_fp_br`、`thorax_distal_transfer_fp_br` 是球速相關性前三名；目前只知道體重是肩部絕對轉移量 (J) 的最強預測因子（R² = 0.481）。
- 待做：
  - [ ] 先寫一篇定義筆記：transfer／generation／absorption 各代表什麼、單位、FP→BR 積分方式。肩部的部分已有 [[肩部STP分解驗證]]（`max(STP + JFP, 0)` 積分）可沿用。
  - [ ] 以 J/kg（或殘差化體重）為目標，篩選動作指標：軀幹轉速、前腳 GRF、肩外旋／水平外展、分離角、身高、手臂長度等。
  - [ ] 以投手為單位、grouped CV 驗證，避免同投手多球膨脹。
  - [x] 拆 JFP 成力、肩膀速度、方向、時間（2026-11-22，見 [[肩部STP分解驗證#JFP 拆成力、肩膀速度、方向與時間]]）：與球速有關的是力大小（partial r 0.57）與肩關節中心速度（0.34）。
  - [x] 拆肩關節中心速度（2026-11-22，見 [[肩關節中心速度來源]]）：與球速有關的 JFP 主要來自重心前進與軀幹下端相對重心往前，不是軀幹旋轉。
  - [ ] **（優先）「軀幹下端相對重心往前」是什麼動作**：檢查是否對應前腳煞車時下半身減速、軀幹繼續前進（與 TODO 2 前腳 GRF 合併做）。
  - [ ] 肩關節中心相對軀幹往後移（JFP −12 J，越多球速越快 r = −0.29）：區分肩胛後收與模型關節中心估計誤差。
  - [ ] 同投手內驗證上述平移來源與球速的關係。
  - [ ] 驗證 FP 姿勢候選 cue（FP 肩水平外展大、FP 肩髖分離大、FP 軀幹旋轉角度仍關著）：用同投手內模型檢查這幾球的肩部轉移是否較多。目前只有投手間相關，狀態為假說。
  - [ ] 重新詮釋軀幹減速：轉移多者 BR 仍保留較高軀幹轉速（[[能量轉移與軀幹旋轉]]）。檢查 STP 兩側抵銷是否只是 `min(|thorax_stp|, |upper_arm_stp|)` 的定義結果：減速多者在軀幹限制時段的軀幹角速度（沿肩力矩方向投影）是否較低。
- 相關：[[能量轉移與軀幹旋轉]]、[[投球手]]

## 2. 前腳地面反作用力 (GRF) 是哪個動作產生的

- 背景：`lead_grf_mag_max` r = 0.42、`lead_grf_z_max` r = 0.40，是動作指標中前段的球速預測因子，但來源未知。
- 候選來源（皆未檢驗）：
  1. 重心前進速度 → 看 COM velocity：POI 有 `max_cog_velo_x`、`cog_velo_pkh`；全訊號可由 `landmarks.csv` 的 `centerofmass_x/y/z` 微分得到時序。
  2. 骨盆旋轉：`pelvis_velo_z`、骨盆旋轉時序（[[骨盆旋轉速度時序分析]]）。
  3. 軀幹旋轉：`max_torso_rotational_velo`、`torso_velo_z`。
- 待做：
  - [ ] 先確認 GRF 峰值時間點相對 `fp_poi_time` 的位置，決定各候選要取哪個時間窗（落地前速度 vs 落地後動作）。
  - [ ] force plate 1,080 Hz、marker 360 Hz，且 force plate 只有 403 球；合併時要核對丟失的球。
  - [ ] 三個候選放同一模型比較獨立解釋量，並控制體重。
  - [ ] 參考舊腳本 `code/py/analyze_grf_predictors.py`（未追蹤、尚未檢查定義是否用 `fp_poi_time`）。
