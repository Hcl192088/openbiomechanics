# 肩胛收縮：主動後拉或慣性留後

## 結論

兩種說法各對應一段時間。**先主動啟動，再靠手臂後擺的動量延續，最後軀幹旋轉把它多拉開一段。** 約 FP 前 66–76 ms 之前，肩峰與上臂在空間中真的往後轉；之後兩者都已往前轉，只是比軀幹慢。單看角度幅度，以空間轉向為切點時「自己往後動」的部分較大（若以軀幹開始正轉為切點，肩胛有較大部分落在切點後，見敏感度段）；最後一段則是被軀幹拉開，且肩膀受力方向與往後拉相反。

狀態：啟動段淨力矩向後、末段慣性拉開皆為**初步支持**；「哪塊肌肉主動收縮」**無法由本資料判斷**（沒有肌電圖）。

## 判斷方法

1. 空間角速度：開角速度 = 軀幹往前轉速 − 上臂（或鎖骨）往前轉速。後者為負，代表真的往後走；為正但小於軀幹，代表被留在後面。
2. 淨力矩／力：扣除重力後向後，代表淨作用在往後拉；向前而角度仍在打開，代表是被拉開、身體前側在抵抗。

## 結果

99 位投手、408 球（3 球標記缺漏排除）。窗口從 FP −300 ms 到角度峰值（不晚於 MER）；先算投手平均，括號為投手 bootstrap 95% CI。

| 階段 | 上臂水平外展增加 | 肩胛後縮代理角增加 |
|---|---:|---:|
| 空間中仍往後走 | 50.8° (45.3–56.0) | 22.4° (20.9–24.1) |
| 已往前轉、但落後軀幹 | 6.3° (5.3–7.4) | 10.6° (9.7–11.5) |
| 分界（相對 FP） | −80 ms | −66 ms |

- 往後走的前半段，扣重力後淨力矩 −5.1 Nm（向後）、肩力 −51.6 N（向後，98% 投手同向）；後半段轉為 +7.8 Nm、+20.0 N（向前），代表在減速，靠動量延續。
- 落後軀幹段：力矩 +31.7 Nm、肩力 +188 N，皆向前，98% 的影格向前。
- 起點改為 FP −200 ms 時，上臂為 27.4° / 6.4°，肩胛為 18.6° / 10.6°。末段穩定，前段大小依起點而變，不報單一百分比。
- FP −60 至 0 ms 軀幹角加速度與末段打開量只有弱關係（肩胛：投手間 r = 0.23、同投手內 −0.08）；軀幹加速越快就拉越開，不支持。
- 與球速：空間中往後走的量 r = 0.26（上臂）、0.18（肩胛），落後量 r ≈ 0；皆弱，未校正體型。

## 敏感度：以軀幹開始正向旋轉為切點

切點 = FP 前 300 ms 內，官方 `torso_velo_z` 最後一次 ≤ 0 的時間（中位數 FP −108 ms）。納入 362 球、92 位投手；46 球在此窗口內軀幹始終為正，無法定義切點而排除。角度自 FP −300 ms 起算。

| | 切點前 | 切點後 | 切點後：仍往後走 | 切點後：落後軀幹 |
|---|---:|---:|---:|---:|
| 上臂 | 39.9° (34.6–45.4) | 18.0° (14.7–21.9) | 12.0° | 6.0° |
| 肩胛 | 12.9° (11.6–14.4) | 20.3° (18.6–22.2) | 10.0° | 10.4° |

- 肩胛後縮較大的部分落在軀幹開始正轉之後，但其中約一半時肩峰在空間中仍往後走；切點後不等於全是慣性留後。
- 切點當下，上臂在空間中仍以 −158°/s、肩胛以 −150°/s 往後轉，因此不是「留在原地」。
- 扣重力淨負荷：切點前上臂 −1.2 Nm（CI −2.5–0.2，無法與零區分）、肩胛 −30.9 N；切點後 +22.6 Nm、+134.7 N。
- 門檻改為 50、100°/s（407、408 球，切點中位數 −92、−81 ms），切點後為上臂 13.6°、11.4°，肩胛 17.1°、15.0°。比例取決於切點定義。

腳本：`baseball_pitching/code/py/analyze_scap_retraction_trunk_onset_split.py`

### 投手間差異與球速

兩種切點（官方 `torso_velo_z`、標記點胸廓角速度）結果相同，以下為官方切點，92 位投手。

- **「軀幹走時留住的量」不是大家都差不多。** 每位投手自己很穩定（ICC 約 0.9），投手之間差很多：上臂切點後 18° ± 15°（投手間 SD，P10–P90 為 0–34°；18% 投手幾乎為 0，上臂在軀幹正轉前已到峰值），肩胛 20° ± 8°（10–29°）。「一開始往後拉」的差異更大：上臂 40° ± 25°（5–77°）、肩胛 13° ± 6°。
- 肩胛前後兩段互相抵換：總量投手間 SD 只有 6.5°，比兩段各自的 SD 還小。早拉多的人，後段拉得少。
- 上臂開多大主要由切點前決定（占投手間總變異約 72%）；肩胛則主要由切點後、肩峰仍往後走的部分決定（約 80%）。純落後軀幹的部分各投手也不同（上臂 6° ± 5°、肩胛 10° ± 5°），但跟總量、球速都無關。
- 與球速（校正體重、身高，每 1 SD 的 mph）：上臂切點前 +0.9（CI 0.0–1.8）、切點後 +0.9（0.2–1.6），**弱支持，分不出哪段較重要**；肩胛兩段 CI 均含 0，**不支持**。同一投手內，各段與球速 |r| ≤ 0.11。
- 切點本身投手間差 32 ms，切點後的量有一部分反映切點早晚；切點前的量依起點 FP −300 ms 而定。

腳本：`baseball_pitching/code/py/analyze_scap_retraction_onset_vs_speed.py`（輸出 `onset_split_variability.csv`、`onset_split_vs_speed.csv`；2026-11-26）

## 驗證與限制

- 官方力矩、力與標記點質量反向動力學逐幀比較，FP 前 r ≥ 0.99，左右投同號；水平外展 r ≥ 0.999。FP–MER 較低（力矩 r 約 0.7–0.8，力約 0.84–0.89），平均值接近。
- 肩胛以 CLAV→肩峰標記近似，有皮膚位移誤差，不是肩胛骨直接量測。
- 淨力矩不能排除共同收縮、被動組織及鎖骨／肋骨接觸力；向前的淨力不代表後縮肌沒有用力。
