# 手套手 (Glove Hand)

手套手的工作主要在於平衡與引導軀幹旋轉。

## 研究數據
- **角度版舊結果**: 落地時 (FP) 的外展角度與球速弱相關 (r = 0.150)，外展速度與球速幾乎無關 (r = -0.008)。
- **肩關節地標位移版**: 以 `fp_poi_time -> BR_time` 計算非投球側肩關節中心位移後，整體 `SJM` 與球速無顯著關聯 (r = 0.025)；分量中以 `SJM_y` 與球速呈弱正相關 (r = 0.152, p = 0.002)。
- **FP 當下位置**: 手套肩在 FP 的局部側向位置 `fp_local_y` 與球速相關較明顯 (r = 0.238, p < 0.001)；FP 當下的垂直位置 `fp_local_z` 也有弱正相關 (r = 0.142, p = 0.004)。
- **第二層時序判讀**: 目前規則式分類幾乎所有投球都落在 `late_pull`，表示現階段證據不支持「大多數高球速投手是先拉得更大再固定」這個說法；較穩妥的描述是，較快球速與 FP 時手套肩已經更偏手套側、位置較高有關，但 FP 後仍常持續移動。

## 生物力學意義
- 手套手通常不直接產生動力，但其肩部在 FP 時若已佔據較好的手套側支點位置，可能更有利於後續軀幹旋轉。
- 目前資料不支持把手套手簡化成「越早固定越好」；更像是 FP 時的位置較重要，而不是整段 `SJM` 越小越快。
