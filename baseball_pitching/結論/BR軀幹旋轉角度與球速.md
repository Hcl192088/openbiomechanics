# BR 軀幹旋轉角度與球速

## 結論

**不支持**「放球時軀幹轉得較少（較少轉過本壘）球速較快」，反方向也不支持。投手之間沒有線性關係，也沒有最佳角度；同一投手內也沒有一致方向。

但這份資料**無法檢驗刻意改變旋轉的技術提示**：同一投手不同球之間，BR 軀幹旋轉只差約 1.4°（SD），遠小於投手之間的 9.4°。刻意使用「胸口朝三壘、不要轉」這類提示時的實際改變量，可能遠超過這個範圍。

## 角度定義

`torso_rotation_br`（`torso_angle_z` 於 BR，朝本壘方向為 +）。全訊號第一幀中位數 -3.2°，所以 0° 約為側身準備姿勢（右投手胸口朝三壘），90° 為胸口正對本壘。BR 中位數 118.5°（IQR 113.2–126.3°，範圍 93.7–144.4°），也就是一般投手放球時軀幹已轉過本壘約 30°，朝一壘方向。

## 結果

411 球、100 位投手；session 群聚校正。

| 檢驗 | 結果 |
|---|---:|
| 線性（控制身高體重） | +0.05 mph/deg, 95% CI [-0.07, +0.17], p = 0.40 |
| 二次項（是否有最佳角度） | p = 0.74 |
| 投手平均 Spearman | ρ = +0.09 |
| 同投手內 | +0.035 mph/deg, p = 0.18 |
| 同投手內，控制 MER 軀幹旋轉 | +0.077 mph/deg, p = 0.073 |
| 個別投手斜率方向（≥ 3 球，91 位） | 轉越少越快 43 位，轉越多越快 48 位 |

依投手平均旋轉角度分五組，平均球速依序為 84.4、83.9、84.4、86.6、84.4 mph（各 20 位），沒有單調趨勢。
