# MER 手肘在肩線前方的來源

## 結論

MER 時手肘跑到雙肩連線前方（Tread 所說的 pushing），在投手之間主要與三件事同時出現：**FP 時肩水平外展較少**（手臂沒有往後打開）、**MER 時軀幹旋轉角度較小**、**較少的真實 layback 加上較多的肘屈曲**。

它和球速的負相關（[[放球時手臂與肩旋轉平面與球速]]）**可以被 FP 肩水平外展完全解釋**：把 FP 肩水平外展放進模型後，「手肘在前方」對球速的效應從每 1° -0.14 mph 變成 +0.03 mph（p = 0.71）。因此「手肘跑到前面」比較像 FP 手臂位置較不開的下游結果，而不是獨立讓球速變慢的原因。狀態：**初步支持**（投手間觀察性關聯，未檢驗因果）。

Tread 列的原因中：

- **#7 假 layback（以肘屈曲代替外旋）**：初步支持。MER 肘屈曲越多，手肘越在前方。
- **#6 layback 受限**：弱支持。最大肩外旋越小，手肘越在前方；但同投手內方向相反。
- **#4 太早打開（flying open）**：不支持。FP 軀幹旋轉與手肘位置無關，FP 肩髖分離只有邊緣關聯。
- **#1 手肘爬太高**：不支持。MER 肩外展與手肘前後位置無關。
- **#3 軀幹前屈取代旋轉**：方向與 Tread 說法相反。MER 軀幹前傾越多，手肘反而越在後方。

**軀幹旋轉角度**（MER 與 BR）與手肘位置關係最強，但與球速無關：BR 軀幹轉得越多，MER 與 BR 時手肘都越在肩線後方，同投手內也一樣；但 BR 軀幹旋轉與球速 r = 0.005，也不能解釋手肘位置與球速的關聯。狀態：手肘位置**初步支持**；球速**不支持**。

### 可能解釋（未檢驗）

放球時手要朝本壘方向出手；軀幹轉得越多，肩線越超過出手方向，手臂相對肩線就自然落在「後方」。若是如此，軀幹旋轉與手肘前後位置部分是出手方向限制下的幾何連動，而不是兩個獨立的技術選擇。

## 結果

逐球 411 球、100 位投手；篩選以投手平均（n = 100）計算，因為原本的球速訊號在投手之間。

| 候選原因（Tread 編號） | 與手肘在前方 r | p | 與球速 r | 加入後「手肘在前方→球速」效應 |
|---|---:|---:|---:|---:|
| MER 軀幹旋轉 | -0.58 | < 0.001 | +0.05 | -0.16, p = 0.031 |
| BR 軀幹旋轉 | -0.55 | < 0.001 | +0.01 | -0.17, p = 0.018 |
| MER→BR 軀幹旋轉增量 | +0.18 | 0.072 | -0.10 | -0.13, p = 0.035 |
| FP 肩水平外展 | -0.57 | < 0.001 | +0.42 | **+0.03, p = 0.71** |
| MER 肘屈曲（#7） | +0.41 | < 0.001 | +0.02 | -0.17, p = 0.009 |
| MER 軀幹前傾（#3） | -0.33 | 0.001 | +0.18 | -0.11, p = 0.095 |
| 最大肩外旋（#6/#7） | -0.29 | 0.004 | +0.36 | -0.08, p = 0.20 |
| FP 肩髖分離（#4） | -0.20 | 0.049 | +0.32 | -0.11, p = 0.072 |
| FP 軀幹旋轉（#4） | -0.08 | 0.43 | -0.04 | -0.14, p = 0.026 |
| MER 肩外展（#1） | +0.08 | 0.43 | -0.02 | -0.13, p = 0.028 |

- 基準：投手平均球速 ~ 手肘在前方 + 身高 + 體重，效應 -0.135 mph/deg，p = 0.026。
- 上表前五項加上 FP 外旋、軀幹峰值轉速、FP 肩髖分離一起放入，可解釋投手間手肘位置變異的 R² = 0.69；MER 軀幹旋轉、FP 肩水平外展、最大肩外旋、MER 肘屈曲、MER 軀幹前傾各自仍顯著。
- 同投手內方向：FP 肩水平外展、MER 軀幹旋轉、MER 肘屈曲與投手間一致；最大肩外旋與 MER 軀幹前傾方向相反。
- BR 軀幹旋轉（中位數 118.5°，IQR 113.2–126.3°）：與 BR 時手肘在前方投手間 r = -0.64，同投手內每 1° 為 -0.32°（p < 0.001）。BR 與 MER 軀幹旋轉同時預測投手平均球速，兩者皆不顯著（p = 0.57、0.39）。多變量模型只保留 MER 軀幹旋轉，因為 BR 值與它高度共線（既有 r = 0.76，見 [[POI動作關聯網分析]]）。
- 手肘前後位置有 81% 變異可用 MER `shoulder_angle_x`（盂肱關節水平內收）解釋，也就是主要是手臂相對胸廓的位置，而不是肩帶本身的移動。

## 限制

- 無法分離肩胛前伸／後縮：`thorax_ap - thorax_prox` 幾乎與雙肩連線平行，不能直接當作胸廓前後軸使用；需先確認 `thorax_ap` 的定義。
- Tread #2（plyo 訓練習慣）、#3 部分內容、#5（舊傷代償）、#6 軟組織限制無法用動作資料直接測量。
- 投手間觀察性分析；「FP 打開肩水平外展會讓手肘不再跑到前面、或球速變快」尚未檢驗。

## 待驗證假說

- FP 肩水平外展較少 → 手臂在旋轉期間「追上」軀幹 → MER 手肘落在肩線前方。這條時序鏈尚未直接檢驗，可用 FP→MER 時序的肩水平外展與軀幹旋轉角度變化來測。
