# 放球時肩水平外展與球速

## 結論

**不支持**「維持肩水平外展至放球會讓同一位投手投得更快」。表面分組中，BR 仍為水平外展者平均球速較快，但差異主要反映投手之間及 FP 起始姿勢的差別；控制這兩項後，估計差異接近零。

實務上不能把「BR 保持正的肩水平外展角度」直接當成提高球速的技術目標。這是觀察性關聯分析，亦不能證明刻意內收或外展沒有其他效果。

## 定義與結果

- 放球事件：`BR_time`。
- 肩水平外展角度：full-signal `shoulder_angle_x` 在 `BR_time` 線性插值；水平外展為正、水平內收為負。
- 維持外展組：BR 角度 `> 0°`；中立／內收組：`<= 0°`。
- 完整資料：411 球、100 位投手；BR 外展組 250 球，中立／內收組 161 球。

| 比較 | 結果 |
|---|---:|
| BR 角度與球速（逐球 Pearson） | r = 0.125, p = 0.011 |
| BR 每增加 1°（依投手群聚校正） | +0.066 mph, p = 0.256, 95% CI [-0.048, 0.179] |
| 外展組平均球速 | 85.34 mph |
| 中立／內收組平均球速 | 83.72 mph |
| 未校正平均差 | +1.61 mph；群聚校正 p = 0.081, 95% CI [-0.20, 3.42] |
| 控制 FP 肩水平外展 | -0.20 mph, p = 0.834, 95% CI [-2.06, 1.66] |
| 同投手內並控制 FP 肩水平外展 | +0.02 mph, p = 0.927, 95% CI [-0.46, 0.51] |

限定 FP 已處於水平外展的 406 球後，250 球維持外展至 BR、156 球在 BR 已中立／內收；控制 FP 角度後，維持組差異為 -0.16 mph（p = 0.866，95% CI [-2.03, 1.71]）。因此粗略的 +1.61 mph 不能解讀為「維持外展使球速增加」。

### 球速至少 140 km/h

以 `pitch_speed_mph >= 140 / 1.609344`（86.99 mph）篩選。角度摘要由同一套 BR 插值結果計算；正值代表水平外展。

- 樣本：144 球、39 位投手。
- 平均：+4.34°；標準差：8.12°。
- 中位數：+5.61°；IQR：-0.52° 至 +10.11°。
- 範圍：-16.13° 至 +22.36°。
- BR 仍為水平外展（`> 0°`）：105/144 球（72.9%）。
